## Fonctionnement du multi-terminaux (Pro)

```
     PC Serveur (caisse principale)
     ├── Stocke toutes les données
     ├── Tournant 24h/7j pendant les heures d'ouverture
     │
     ├── PC Caisse 2  ──┐
     └── PC Caisse 3  ──┘  Connectés via Wi-Fi ou câble réseau local
```

- Pas d'internet requis — tout se passe sur votre réseau local (box/routeur)
- Chaque caissier se connecte avec son propre compte
- Les ventes de toutes les caisses sont centralisées en temps réel
- Si le Wi-Fi coupe : la caisse principale continue seule

## Questions fréquentes

**Est-ce que j'ai besoin d'internet ?**
Non. L'application fonctionne entièrement hors ligne. Internet est utilisé uniquement pour l'activation initiale de la licence.

**Que se passe-t-il si mon PC tombe en panne ?**
Vos données sont dans le fichier `boutique.db`. Copiez-le sur une clé USB régulièrement (la sauvegarde auto Pro le fait pour vous). En cas de panne, on vous aide à restaurer.

**Puis-je essayer avant d'acheter ?**
Oui. Le mode démo offre 50 ventes gratuites pendant 14 jours, sans carte bancaire.

**Puis-je passer de Standard à Pro plus tard ?**
Oui. Achetez simplement la clé Pro et activez-la. Toutes vos données (ventes, stock, clients) sont conservées.

**HishamPOS fonctionne sur quel PC ?**
Windows 10 ou 11, 64 bits. RAM : 4 Go minimum. Disque : 500 Mo libres.
