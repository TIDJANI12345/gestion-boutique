## 1️⃣ INTRODUCTION

### Bienvenue !

**Gestion Boutique** est un logiciel de gestion complet conçu spécialement pour les boutiques et commerces au Bénin et en Afrique.

### Fonctionnalités principales

✅ **Gestion des ventes** - Scanner de codes-barres, panier, validation rapide
✅ **Gestion des produits** - Stock, alertes, catégories
✅ **Reçus PDF** - Génération automatique de reçus professionnels
✅ **Rapports** - Statistiques, chiffre d'affaires, top produits
✅ **Export WhatsApp** - Partage de catalogues avec vos revendeurs
✅ **Hors ligne** - Fonctionne sans connexion internet

### Configuration requise

- **Système** : Windows 10 ou 11
- **RAM** : 4 GB minimum (8 GB recommandé)
- **Disque** : 500 MB d'espace libre
- **Écran** : 1366x768 minimum

## 2️⃣ INSTALLATION

### Étape 1 : Télécharger

Vous avez reçu le fichier **GestionBoutique_Setup_v2.0.0.exe**

### Étape 2 : Installer

1. **Double-cliquez** sur le fichier d'installation
2. Si Windows demande "Voulez-vous autoriser ?" → Cliquez **Oui**
3. Choisissez la **langue** : Français
4. Cliquez **Suivant**
5. Acceptez les termes → **Suivant**
6. Choisissez le dossier (laissez par défaut) → **Suivant**
7. Cochez "Créer un raccourci sur le bureau" → **Suivant**
8. Cliquez **Installer**
9. Attendez la fin de l'installation
10. Cliquez **Terminer**

✅ **L'installation est terminée !**

### Étape 3 : Premier lancement

Un raccourci **"Gestion Boutique"** est créé sur votre bureau.

Double-cliquez dessus pour lancer l'application.

## 4️⃣ GUIDE DES FONCTIONNALITÉS

### 📊 Tableau de bord

Le tableau de bord affiche :
- **Ventes aujourd'hui** - Nombre de ventes du jour
- **Chiffre d'affaires** - CA total du jour
- **Produits en alerte** - Produits avec stock faible
- **Dernières ventes** - Liste des 5 dernières ventes
- **Stock faible** - Produits à réapprovisionner

### 💳 Nouvelle vente

**Comment faire une vente ?**

1. Cliquez sur **"💳 Nouvelle vente"**
2. **Scannez** le code-barre du produit (ou tapez-le)
3. Appuyez sur **Entrée**
4. Choisissez la **quantité**
5. Le produit s'ajoute au panier
6. Répétez pour tous les produits
7. (Optionnel) Entrez le **nom du client**
8. Cliquez **"✅ Valider la vente"**
9. Le **reçu PDF** se génère automatiquement
10. Vous pouvez l'**imprimer** ou l'envoyer par email

### ➕ Ajouter un produit

**Comment ajouter un nouveau produit ?**

1. Cliquez sur **"➕ Ajouter produit"**
2. Remplissez les informations :
   - **Nom** : Nom du produit
   - **Catégorie** : Alimentaire, Hygiène, etc.
   - **Prix vente** : Prix de vente en FCFA
   - **Stock actuel** : Quantité en stock
   - **Stock alerte** : Seuil d'alerte (ex: 5)
   - **Code-barre** : Généré automatiquement ou manuel
3. Cliquez **"Enregistrer"**

✅ Le produit est ajouté !

### 📜 Liste des ventes

Affiche **toutes les ventes** enregistrées.

**Actions disponibles :**
- 👁️ **Voir détails** (double-clic)
- 🖨️ **Réimprimer** un reçu (clic droit)
- 🗑️ **Supprimer** une vente (avec confirmation)

### 📊 Rapports

3 onglets disponibles :

**1. Vue d'ensemble**
- Statistiques du jour
- Total des ventes
- Valeur du stock

**2. Top Produits**
- Produits les plus vendus
- Quantités vendues
- CA généré par produit

**3. Stock Faible**
- Liste des produits à réapprovisionner
- Seuil d'alerte atteint

### 📱 Export WhatsApp

**Créer un catalogue pour WhatsApp :**

1. Cliquez sur **"📱 Export WhatsApp"**
2. Sélectionnez les **catégories** à exporter
3. Choisissez le **style** (avec ou sans emoji)
4. Prévisualisez le message
5. Cliquez **"📋 Copier"**
6. Collez dans WhatsApp et envoyez !

**Exemple de résultat :**
```
🛒 CATALOGUE - Ma Boutique

📦 ALIMENTAIRE
- Riz Uncle Ben 5kg - 7,500 FCFA
- Huile Dinor 1L - 2,500 FCFA

🧴 HYGIÈNE
- Savon Lux - 250 FCFA
- Dentifrice Colgate - 1,200 FCFA

📞 Contact : +229 XX XX XX XX
```

## 5️⃣ FAQ (FOIRE AUX QUESTIONS)

### ❓ J'ai perdu ma clé de licence

Contactez le support avec :
- Votre **nom** ou **nom de boutique**
- Votre **numéro de téléphone**
- La **date d'achat**

Nous vous renverrons votre clé.

### ❓ Ma licence a expiré

Contactez-nous pour **renouveler** votre licence :
- Email : support@votreentreprise.bj
- Tél : +229 XX XX XX XX

### ❓ L'application ne se lance pas

**Solutions :**
1. Redémarrez votre ordinateur
2. Désinstallez et réinstallez
3. Vérifiez que vous avez Windows 10/11
4. Contactez le support

### ❓ Je ne trouve pas mes données

Les données sont stockées dans :
```
C:\Program Files\GestionBoutique\data\
```

**Sauvegardez régulièrement** ce dossier !

### ❓ Comment faire une sauvegarde ?

1. Allez dans `C:\Program Files\GestionBoutique\data\`
2. Copiez le fichier **boutique.db**
3. Collez-le sur une **clé USB** ou **Google Drive**
4. Datez la sauvegarde (ex: boutique_2026-01-24.db)

### ❓ Mon imprimante ne fonctionne pas

Le PDF se génère dans :
```
C:\Program Files\GestionBoutique\recus\
```

Vous pouvez :
- Ouvrir le PDF et imprimer manuellement
- Envoyer par email au client

### ❓ Puis-je utiliser sur plusieurs ordinateurs ?

**NON**. Une licence = 1 ordinateur.

Pour plusieurs PC, achetez une licence par PC.

### ❓ Puis-je personnaliser les reçus ?

Oui ! Contactez le support pour :
- Ajouter votre **logo**
- Modifier les **informations** (nom, adresse, téléphone)
- Changer les **couleurs**
