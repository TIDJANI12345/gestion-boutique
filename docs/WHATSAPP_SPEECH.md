# Scripts WhatsApp — Conversion des Leads Publicitaires
> À utiliser pour répondre aux personnes qui écrivent via les pubs Facebook/Instagram

---

## RÈGLE D'OR

**Répondez en moins de 5 minutes.** Un lead chaud refroidit vite. Après 1h, la moitié des gens sont passés à autre chose.

## 3. GESTION DES OBJECTIONS

### "C'est trop cher"

```
Je comprends votre préoccupation. Permettez-moi de vous donner une autre perspective :

40 000 F ÷ 12 mois = 3 333 F par mois.
C'est moins qu'une recharge téléphone par semaine.

Et c'est une seule fois — pas d'abonnement. Dans 5 ans, vous payez toujours 0 F par mois.

Beaucoup de commerçants perdent plus que ça en erreurs de stock ou en ventes non comptabilisées.

Et si vous voulez tester d'abord ? Le mode démo est totalement gratuit.
```

### "J'ai déjà un logiciel"

```
D'accord ! Qu'est-ce que vous utilisez actuellement ?

Je vous pose la question parce que HishamPOS a des fonctions que beaucoup de logiciels n'ont pas :
- Fonctionne sans internet (pas de problème de connexion)
- Licence perpétuelle (pas d'abonnement mensuel)
- Multi-terminaux sans serveur cloud
- Support en français, adapté au contexte béninois (IFU, RCCM, FCFA)

Si votre logiciel actuel vous satisfait à 100%, tant mieux.
Mais si vous payez un abonnement mensuel, HishamPOS peut vous faire économiser sur le long terme.
```

### "Ça marche vraiment ?"

```
Absolument. Voici comment vous pouvez vous en assurer :

1️⃣ Téléchargez le mode démo gratuitement sur hishamdigital.com
2️⃣ Installez sur votre PC (Windows 10 ou 11)
3️⃣ Faites 50 vraies ventes de test pendant 14 jours
4️⃣ Si ça vous convient → vous activez avec la clé achetée

Vous ne me croyez pas sur parole — vous le voyez fonctionner dans votre boutique.
```

### "Je vais y réfléchir"

```
Bien sûr, prenez le temps qu'il vous faut.

Pendant que vous réfléchissez : est-ce que vous avez des questions spécifiques ?
Parfois une hésitation vient d'un détail qu'on peut clarifier tout de suite.

Et si vous voulez, téléchargez le démo — ça ne coûte rien et ça vous donnera une idée concrète.

Je suis disponible si besoin 🙂
```

### "Est-ce que ça marche avec mon imprimante ?"

```
Ça dépend du type d'imprimante.

Les imprimantes thermiques ESC/POS (les petites qui impriment les tickets) :
→ Oui, compatibles. Marques : Xprinter, Epson TM, Star, Bixolon, et la plupart des clones chinois.

Les imprimantes normales laser/jet d'encre :
→ Oui aussi, via PDF (vous ouvrez le reçu PDF et imprimez depuis Adobe/Chrome).

Quel modèle avez-vous ?
```

### "Je suis à l'intérieur du Bénin / dans un autre pays"

```
Aucun problème ! La livraison se fait entièrement en ligne :

1. Vous payez sur le site (Mobile Money, carte, virement)
2. Vous recevez votre clé de licence par WhatsApp/email
3. Vous l'activez depuis n'importe où avec une connexion internet
4. Ensuite le logiciel fonctionne sans internet

On a des clients à Parakou, Abomey, Porto-Novo et en Côte d'Ivoire.
```

## 6. POINTS CLÉS À RETENIR

- **Ne jamais pitcher le prix en premier.** Comprendre le besoin d'abord, proposer le plan adapté ensuite.
- **Le démo est votre meilleur vendeur.** Proposez-le à chaque hésitant — qui teste achète souvent.
- **"Perpétuel" est l'argument qui tue.** Beaucoup de gens fuient les abonnements. Insistez là-dessus.
- **Répondez vite.** Dans la pub WhatsApp, la concurrence est à 1 clic.
- **Personnalisez.** Utilisez le prénom dès le deuxième message.
- **Fermez avec une question ouverte.** "Une question avant de finaliser ?" garde le dialogue ouvert.
